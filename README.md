One word for the whole internet: **babble** — everyone talking at once,
nobody listening. The program writes exactly that word (no trailing newline)
to `/output/entry.txt`, inside the 1–30 character gate. Entry for make.fun's
"The Internet in One Word" bounty ($10 USDC).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
